# Deployment Guide

## Hardware Requirements

* CPU: 2 cores minimum
* RAM: 4GB minimum
* Disk: 1GB free space

## Software Requirements

* Python 3.10+
* pip
* virtualenv

## Network

* Port 5500 must be open

## Deployment Steps

1. Clone repository
2. Install dependencies
3. Train model
4. Run:
   streamlit run app.py

## Verification

Open http://127.0.0.1:5500/ and upload an image
